Machine

One bit for every cut, so each file needs no bit change. The page tells students which bit it is. Changing the bit? Press Starting values on each material.

Materials

Board size is the piece students design on, not the machine table. Feeds are starting values, not tested at school (docs/HARDWARE.md). Watch the first cut and slow down if the router bogs or the bit squeals. Clamps marks where your clamps hold the board: students see them grey, and no cut may come near them. Choose tape if you hold boards down with double-sided tape.
