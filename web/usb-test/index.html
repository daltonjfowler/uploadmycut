What this page does

It connects to the Shapeoko over USB and asks four questions: status, version, settings list and parser state. It cannot move the machine, turn anything on, or change a setting. Nothing else can be sent from this page.

  1. Close Carbide Motion (only one program can use the USB port).
  2. Plug the Shapeoko's USB cable into this computer and switch the machine on.
  3. Press Connect and pick the port (on Windows usually a COM port).
  4. Press Ask everything, then Save report and send the file to Dalton / Rocky.

Good to know: connecting restarts the controller, like Carbide Motion does. Nothing moves, but afterwards Carbide Motion will ask you to initialize (home) the machine again. That is normal.

This browser cannot use USB serial. Use Chrome or Edge on a computer (Chromebooks may need the district to allow it).
