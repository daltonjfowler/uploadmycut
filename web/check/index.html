Only run files that pass this check

A student can hand you any .nc file, not only one this site made. This page runs the same safety check the student page runs before every download, with the class limits saved right now: on the board, not too deep, not too fast, no machine settings or unlock commands. The file stays on this computer. Nothing is uploaded.

  1. Drop the student's .nc file (and its -frame.nc) below, or press Choose files.
  2. Check the material the page used matches the board on the machine.
  3. Run it in Carbide Motion only if it says OK to run. If it says Do not run, ask the student to make the file again on the student page.

Still at the machine: passing this check does not replace the frame check, eye protection, or standing at the machine for the whole cut. Feed hold does not stop the router: switch the router off too.
